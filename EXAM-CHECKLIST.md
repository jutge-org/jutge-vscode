## Pre-Exam

- [x] You can't see available exams until you have entered your password.

- [x] You can't enter an exam if you don't know its password.

## Problems

- [x] You can't access normal problems during an exam.
      (By using "Jutge.org: Show Problem" command).

- [x] You can submit problems in the exam.

## Status

- [x] You see the time remaining go down little by little.

- [x] The status of each problem refreshes when you send a problem.

- [x] If you get a WA after an AC, it still shows AC.
      (The way verdicts get aggregated is something that could be
      configured.)

- [x] If you close VSCode, when you open it again, it recovers the
      state (logged in the exam, open problems).

- [ ] If the problems or the time limit of the exam changes, it is
      refreshed automatically. I.e. you don't need to press the refresh
      button.

## User Finishing

- [x] If you have finished your exam, you can't login again.
      To fix this, the tutor can "unfinish" you.

## Exam ending

- [x] You can still send problems with seconds away from the end.

- [ ] Once the exam has ended, you can't submit through the API.

- [ ] Once the exam has ended, you can't: - View problems. - View documents. - Submit.
      you can only finish the exam.

- [ ] Once the exam has ended, the panel does not show the problems,
      only a message inviting you to finish.
