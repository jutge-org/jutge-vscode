1. Go to Microsoft Azure (portal.azure.com).
2. In the searchbox, type "DevOps", and select the option "Azure DevOps Organizations".
3. Click on "View My Organizations". This will go [here](https://aex.dev.azure.com/me?mkt=ca-ES), probably a shortcut.
4. Click on the "Jutge VSCode" project ([url](https://dev.azure.com/jutge-org/Jutge%20VSCode)).
5. Typically, you have to create a new "Personal Access Token" in the settings for the project (upper right corner).
6. Copy that token and use it when running `bun run vsce:publish`.
